# My Daily Habits

A simple habit tracker made with HTML, CSS, and JavaScript.

You can add habits, check them off, and see how many you have completed. The reminder messages are read from `daily-notes.txt` using `fetch`.

## How to run

The browser needs a local web server to read the text file. In this folder, run:

```powershell
py -m http.server 8000
```

Then open http://localhost:8000 in your browser. You can also use the VS Code Live Server extension.
